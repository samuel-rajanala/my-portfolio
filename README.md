# Sam Rajanala — Cybersecurity Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, and Tailwind CSS. It highlights Sam's cybersecurity interests, experience, selected projects, and contact links.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Lenis smooth scrolling
- Custom scroll- and pointer-driven interactions
